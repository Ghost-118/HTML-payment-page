# HTML Payment Page

Página web de procesamiento de pago (*checkout*) desarrollada con **HTML5** semántico, enfocada en la validación de formularios y mejores prácticas de accesibilidad[cite: 10]. Muestra un resumen del producto en el carrito y un formulario para el ingreso de datos de tarjeta de crédito/débito[cite: 10].

---

## 🚀 Características

- **Resumen de Compra:** Muestra detalles del producto (imagen, cantidad y precio) organizados en secciones claras.
- **Formulario Accesible:** Uso de etiquetas `<label>` vinculadas con `for`, atributos `aria-describedby` para textos de ayuda y `aria-hidden="true"` en elementos indicativos.
- **Validación Nativa:** Campos requeridos (`required`) para asegurar que el usuario complete los datos obligatorios antes de enviar.
